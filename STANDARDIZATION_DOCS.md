# Документація: Модуль Стандартизації Речей (AI Studio Cutout & Catalog Search)

## 1. Проблема та Концепція (Чому це важливо)
У реальному житті користувач фотографує одяг на підлозі, ліжку або вішалці під різним освітленням і кутами. Якщо зберігати такі «сирі» фото, візуальна сітка гардероба виглядає неохайно й строкато.

**Мета стандартизації:** привести кожну річ до вигляду професійного студійного каталогу (Flat-lay / Studio product look) з мінімальними витратами ресурсів, без серверів і сторонніх платних API.

---

## 2. Архітектурне Рішення (Комбінований Підхід)

Система стандартизації складається з **двох взаємодоповнюючих механізмів**:

### А. Локальне очищення фону (Client-Side Studio Cutout)
- **Файл:** `src/utils/backgroundRemoval.ts` -> `processStudioCutout()`
- **Принцип роботи:**
  1. Алгоритм зчитує стиснений кадр на offscreen HTML5 Canvas.
  2. Виконує автоматичне сканування периметра зображення (верхні, нижні та бічні краї), визначаючи колірний профіль фону (простирадло, килим, ламінат тощо).
  3. Обчислює колірну відстань в евклідовому просторі RGB з адаптивним порогом чутливості (`sensitivity: 35`).
  4. Формує м'яку маску прозорості (alpha feathering) для згладжування країв тканини.
  5. Переносить виділений одяг на чистий студійний фон (`#f8fafc` з радіальним софт-освітленням або прозорий PNG).
- **Плюси:** Миттєво (30–60 мс), працює офлайн на пристрої, не потребує підключення до серверів.

### Б. Глибока ШІ-ідентифікація та Пошук Каталожного Фото (Gemini + Web Catalog)
- **Файл:** `src/services/geminiService.ts` -> `analyzeClothingImage()`
- **Принцип роботи:**
  1. `gemini-2.5-flash` аналізує фото не лише на категорію, а й визначає:
     - `brand`: розпізнавання бренду або маркування (наприклад, *Uniqlo, Zara, Nike, Levi's* або *Generic*).
     - `name`: точний фасон/модель товару (наприклад, *«Heavyweight Boxy Crewneck Tee»*).
     - `searchQuery`: готовий оптимізований пошуковий запит для пошуку студійного фото товару (наприклад, *«Uniqlo Heavyweight Boxy Crewneck Tee Washed Black product photo»*).
  2. У модальному вікні користувачу доступні 2 інструменти:
     - **«Find Catalog Photo» (Google Images):** відкриває в один клік видачу Google Images з офіційними фотографіями цього товару на білому тлі.
     - **«Paste Catalog Image URL»:** дозволяє скопіювати посилання на офіційне фото з інтернет-магазину та в один клік імпортувати його замість домашнього фото з ліжка.

## 3. Зміни в Базі Даних (Dexie.js)
Модель `WardrobeItem` в [`src/db/db.ts`](file:///Users/skycherepanya/Documents/antigravity/bold-mendeleev/src/db/db.ts) розширена новими полями:

```typescript
export interface WardrobeItem {
  id: string;              // UUID
  imageBase64: string;     // Стандартизоване або студійне фото
  category: WardrobeCategory;
  color: string;
  season: Season | string;
  isClean: boolean;
  createdAt: number;
  
  // Нові поля стандартизації:
  name?: string;           // Назва моделі/фасону (наприклад: "Slim Fit Chino")
  brand?: string;          // Бренд (наприклад: "Zara")
  isCutout?: boolean;      // Чи застосовано алгоритм видалення фону
  searchQuery?: string;    // Збережений запит для пошуку в мережі
}
```

## 5. Чеклист для Подальшого Аудиту Агентами («Офіс Агентів»)

Коли ви запустите команду агентів для полірування, вони можуть зосередитись на таких напрямках:
- [ ] **Тестування периметра canvas-маски:** перевірка роботи алгоритму на контрастних фонах (наприклад, червона річ на чорному простирадлі vs біла річ на білій підлозі).
- [ ] **Підтримка WebAssembly Rembg (опціонально):** інтеграція легкої ONNX-моделі для вибіркового сегментування складних фактур (хутро, бахрома).
- [ ] **CORS Proxy для URL:** безпечне завантаження зовнішніх фото брендів, якщо сервер магазину блокує прямі запити `fetch()`.
- [ ] **Оновлення E2E-тестів:** додавання тест-кейсів для нових полів `brand`, `name`, `isCutout`.
